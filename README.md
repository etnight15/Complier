# Лабораторная работа №1

## Название и цель лабораторной работы
Название: Разработка пользовательского интерфейса (GUI) для языкового процессора.
Цель: Создание кроссплатформенного графического интерфейса (GUI) для языкового процессора в виде специализированного текстового редактора.

## Сведения об авторе
Марков Д.Д., АВТ-314

## Описание проекта
Оконное приложение представляет собой текстовый редактор с графическим интерфейсом, реализующий базовые операции работы с текстовыми файлами. Включает главное меню, панель инструментов, область редактирования и область вывода результатов. Приложение разработано с учетом дальнейшего расширения функционала для создания языкового процессора.

## Используемые технологии
Python 3.9+, PyQt6
Среда разработки: VS Code

## Инструкция по сборке и запуску

```bash
# Активация виртуального окружения
# Windows:

# Linux/Mac:
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

## Диагностика и нейтрализация синтаксических ошибок
Метод Айронаса явлетеся алгоритмом восстановления после синтаксических ошибок, который позволяет продолжить анализ программы даже при обнаружении ошибки. В моем синтаксическом анализаторе он разработан через механизм пропуска ошибочных токенов до встречи с ожидаемыми символами. При обнаружении ошибки анализатор фиксирует ошибку и вызывает функцию _skip_until(), которая последовательно удаляет из входного потока все токены, не входящие в множество допустимых символов для текущего этапа. Как только встречается ожидаемый токен, разбор продолжается.

Пример:
<img width="1919" height="352" alt="image" src="https://github.com/user-attachments/assets/456f643d-b96e-4298-ba78-659c07f85c4c" />
<img width="1917" height="398" alt="image" src="https://github.com/user-attachments/assets/f5e4e500-56f6-4f5e-889d-0fe67ac5c325" />

В данном примере анализатор работает следующим образом: Проверят первый токен и фиксирует ошибку, далее вызывается функция и пропускает токен real, продолжается анализ и в конце строки проверяет ";" и фиксирует вторую ошибку.

```

```

## Контекстно-зависимые условия
| № | Проверка | Пример | Ожидаемое сообщение |
|---|----------|--------|----------------------|
| 1 | Уникальность имён | `const a: real = 1.0;`<br>`const a: real = 2.0;` | Повторное объявление идентификатора 'a' |
| 2 | Совместимость типа и инициализатора | `const x: real = y;` | Несовместимость типов: объявлен 'real', а получен '<тип>' |
| 3 | Использование только объявленных идентификаторов | `const b: real = a;` | Идентификатор 'a' не объявлен |
| 4 | Корректный пример (без ошибок) | `const pi: real = 3.14;` | Семантических ошибок не обнаружено. |

## Структура AST

### Описание типов узлов
| Тип | Назначение |
|-----------|------------|
| program | Корень программы: список объявлений констант. Дочерние узлы — const_declaration. |
| const_declaration | Объявление вида const имя : тип = значение ;. |
| keyword | Ключевое слово const. |
| identifier | Имя константы (pi). |
| type | Имя типа данных (real). |
| value | Вещественный литерал инициализатора (3.14). |

## Вариант задания

Полное определение грамматики:
```
E → TA
A → ε | + TA | - TA
T → FB
B → ε | * FB | / FB
F → num | id | (E)
id → letter {letter | digit}
num → digit {digit}
```

Примеры верных строк:
```
1 + 2 * 3
(1 + 2) * 3
a+1
(10 + 5) * 2 - 3
```

Преобразование и анализ кода с использованием Clang и LLVM

## Цель работы
Познакомиться с инструментами Clang и LLVM, научиться получать абстрактное синтаксическое дерево (AST) и промежуточное представление (LLVM IR) для кода на C/C++, применять базовые оптимизации, строить граф потока управления (CFG), а также проанализировать влияние оптимизаций на синтаксические конструкции языка.

## Постановка задачи
1. Установить Clang, LLVM, opt и Graphviz.
2. Скомпилировать простой C-файл и получить AST и LLVM IR.
3. Использовать opt для оптимизации IR.
4. Построить CFG до и после оптимизаций.
5. Выполнить индивидуальное задание по варианту.

## Общая часть работы
### Заданный исходный код
```
#include <stdio.h>

int square(int x) {
    return x * x;
}

int main() {
    int a = 5;
    int b = square(a);
    printf("%d\n", b);
    return 0;
}
```

### Получение AST
Команда:
```
clang -Xclang -ast-dump -fsyntax-only main.c
```
Результат:

### Оптимизация IR через opt
Команда:
```

```

### Построение CFG 
До оптимизации:
```
opt -passes=dot-cfg -disable-output main_O0.ll
dot -Tpng .main.dot -o main_cfg_O0.png
```

После оптимизации:
```
opt -passes=dot-cfg -disable-output main_O2.ll
dot -Tpng .main.dot -o main_cfg_O2.png
```
