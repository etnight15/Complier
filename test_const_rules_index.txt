Индекс к файлу test_const_rules_samples.txt
(какой фрагмент к какой проверке относится; ожидаемый слой: лексика / синтаксис)

Успешные
  T_OK_* — без ошибок на всех этапах.

Лексика
  T_LEX_AT, T_LEX_HASH, T_LEX_BANG — недопустимый символ (не из алфавита лексера).
  T_LEX_DOT — одиночная точка после '=' даёт лексическую ошибку.

Синтаксис (парсер), по блокам в samples-файле
  Только ;;;; — ожидается ключевое слово const.
  cont T_TYPO — ожидается const, найдено другое слово (опечатка con…).
  3.14 T_NO_CONST — в начале ожидается const, а не число.
  const real: real — real вместо идентификатора имени константы.
  abc real = 3.14 — пропущен const в начале (паттерн «имя имя =»).
  100 T_NUM_BEFORE — пропущен const; число вместо имени.
  const ; T_STRAY_SEMI — лишняя ; перед именем.
  const ;; T_MULTI_SEMI — несколько лишних ; перед именем.
  ; T_SPURIOUS — лишний токен в начале.
  const const T_DUP_CONST — повтор const вместо имени.
  const T_EXTRA A — лишний идентификатор перед ':'.
  const T_NO_COLON real — пропущен ':' между именем и типом.
  const T_ASSIGN_BEFORE_TYPE: := real — ':=' вместо ':' перед типом.
  const T_NO_ASSIGN: real 3.14 — пропущен '='.
  const T_NO_NUM: real = — нет числового литерала после '='.
  const T_SEMI_BEFORE_EQ — лишняя ; перед '='.
  const T_SEMI_BEFORE_NUM — лишняя ; перед числом.
  const T_NO_FINAL_SEMI — нет завершающего ';' (конец файла/строки).
  T_DOUBLE_COLON:: — повторяющийся ':'.
  T_DOUBLE_EQ: real == — повторяющийся '='.
  T_DOUBLE_SEMI: … 3.14;; — повторяющийся ';'.
  const T_BAD_NUM: real = 3.k4; — некорректное вещественное число (ожидается число формата d+.d+).
  ??? garbage — неожиданная последовательность и синхронизация.

Замечание
  Анализ в проекте ограничен лексическими и синтаксическими проверками.
